## 🎯 Notre Démarche

Chez **Wavenet**, on ne fait pas les choses à moitié ! Quand IAKA nous a lancé le défi du **Bar à Prompts**, notre équipe de prompt engineers s'est retroussée les manches (et a sorti les shakers virtuels 🍹).

Notre mission ? Créer une **carte de cocktails promptologiques** dignes des meilleurs bars... mais version IA ! Chaque prompt de ce repository a été :

- ✅ **Testé en conditions réelles** sur des problématiques métier
- ✅ **Structuré avec amour** pour être compréhensible et adaptable
- ✅ **Baptisé avec créativité** (parce qu'un bon prompt mérite un bon nom de cocktail)

Le résultat ? Une collection de prompts prêts à être servis sur table basse, entre deux fauteuils confortables, pour aider les visiteurs à découvrir la magie des LLM ! 🪄

## 📋 Le Challenge Original

### ❗❗❗ A LA RECHERCHE DE PROMPTEURS ❗❗❗

#### Le concept

> *« Le bar à prompts est un lieu de découverte et d'approfondissement du potentiel des LLM au plus près du besoin des visiteurs. Chaque visiteur vient à la rencontre d'un prompt engineer pour échanger sur ses besoins métier et découvrir en regard ce qu'un LLM peut lui apporter, dans une ambiance détendue (deux fauteuils, une table basse, son PC et des mocktails dans une déco type bar), entamer le dialogue avec le visiteur en 1 to 1 pour découvrir son contexte et besoin et lui proposer un ou des exemples de prompts à partir d'un menu. »*

#### Pourquoi Wavenet y participe ?

Ces prompts seront diffusés sur un **Github public de IAKA** et utilisés dans leurs évènements au travers de partage par QR Code sur des sous-bocks, dans des présentations... C'est donc une belle visibilité pour notre entreprise et une manière de montrer que nous avons des compétences de prompting et de création d'agents !

#### Les critères du challenge

Un prompt gagnant doit :

- 🎯 **Avoir aidé à résoudre une problématique métier** (ou pouvoir y répondre)
- 🍸 **Avoir un titre original typé "nom de cocktail"** en lien avec la problématique
- 📝 **Être compréhensible et structuré** (professionnalisme oblige !)
- 🔄 **Être adaptable/générique** pour pouvoir le travailler pendant la session
- 🍽️ **De l'entrée au dessert** : des plus simples aux plus complexes, toutes les idées sont les bienvenues !

#### Contenu attendu pour chaque prompt

| Champ | Description |
|-------|-------------|
| **Titre** | Nom de cocktail créatif |
| **Description menu** | Style fun pour la carte |
| **UseCase** | Description traditionnelle du cas d'usage |
| **Thème** | Catégorie principale |
| **Sous-thème** | Spécialisation |
| **Plateforme** | ChatGPT, Claude, Mistral, etc. |
| **Contenu** | Le prompt lui-même |

#### Thèmes disponibles

- **Rédaction** : Emails, articles, rapports, LinkedIn, synthèses, traduction...
- **Productivité** : Présentations, formations, extraction de données, analyse de risques, to-do lists...
- **Production de contenus visuels** : Images, vidéos, infographies...
- **Créativité** : Brainstorming, génération de concepts...
- **Coach dédicacé** : Accompagnement personnalisé
- **Autres** : Tout ce qui ne rentre pas dans les cases !
